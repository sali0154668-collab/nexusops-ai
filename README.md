\# NexusOps AI Productivity Agent



An automated productivity operations agent powered by Google Gemini AI, built using FastAPI for the backend and Streamlit for the frontend.



\## Project Structure

\- `backend.py`: FastAPI server handling the Gemini API integration.

\- `app.py`: Streamlit user interface for the productivity agent.

\- `requirements.txt`: List of required Python packages.
